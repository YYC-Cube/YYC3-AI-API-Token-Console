# 06 · 安全与审计（security）

> 页面：`/settings` → 「安全设置」（`SecuritySection`）；关联页 `/security`（安全监控）· `/audit`（操作审计）· `/users`（用户管理）
> P4 服务端下发：本区 4 键为 `PUT /console/settings` 白名单成员（console-server 持久化 `console-settings.json`）

## 认证与会话

| 变量 | 类型 | 默认 | 示例 | 说明 / 生效 |
| ---- | ---- | ---- | ---- | ---- |
| `toggles.mfa` | boolean | `true` | 开/关 | 多因素认证开关 |
| `values.sessionTimeout` | string | `"30"` | `45`（分钟） | 会话超时。**保存时下发** `sessionTimeoutMin`（合法 1-1440） |
| `toggles.rateLimiting` | boolean | `true` | 开/关 | 速率限制（登录限流 5 次/5min/IP 为服务端常量） |
| `values.ipWhitelist` | string（多行） | `"192.168.1.0/24\n10.0.0.0/16\n172.16.0.0/12"` | 每行一个 CIDR | **保存时下发**服务端白名单 |

## 访问与审计

| 变量 | 类型 | 默认 | 示例 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| `toggles.corsEnabled` | boolean | `true` | 开/关 | 跨域开关（服务端 CORS_ORIGINS 下发面） |
| `toggles.auditLog` | boolean | `true` | 开/关 | 操作审计记录（/audit 页消费） |

## P4 下发协议（实况）

```
「保存更改」→ PUT /console/settings
  body: { ipWhitelist, alertEmailAddr, webhookUrl, sessionTimeoutMin }
  console-server: 白名单校验(类型/长度/范围) → merge → 原子落盘 → 回执 rejected 清单
  本地/无后端: 前端侧已生效, 下发静默降级
```
