# 03 · 集群与负载（cluster）

> 页面：`/settings` → 「集群配置」（`ClusterSection`）；监控消费页 `/`（数据监控）· `/operations`（操作中心）
> 生效：即时（展示与规则参数），健康检查周期于下一轮巡查生效

## 弹性伸缩

| 变量 | 类型 | 默认 | 示例 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| `toggles.autoScale` | boolean | `true` | 开/关 | 自动伸缩总开关 |
| `values.scaleUpThreshold` | string | `"85"` | `90`（%） | 扩容触发阈值（负载 ≥ 触发） |
| `values.scaleDownThreshold` | string | `"30"` | `20`（%） | 缩容触发阈值 |
| `values.maxNodes` | string | `"16"` | `8` | 集群节点上限 |

## 负载与健康

| 变量 | 类型 | 默认 | 示例 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| `values.loadBalanceStrategy` | string | `"轮询 (Round Robin)"` | `最小连接数` | 负载均衡策略 |
| `toggles.healthCheck` | boolean | `true` | 开/关 | 健康检查开关 |
| `values.healthCheckInterval` | string | `"30"` | `15`（秒） | 健康检查间隔 |
| `values.maxConcurrency` | string | `"100"` | `200` | 最大并发数 |

## 与实况数据的关系

- 节点实况（在线率/延迟/模型负载）来自 `/console/metrics` 聚合（巡查实况检查项同源，见 [07 通知与告警](./07-通知与告警.md)）
- 巡查页 `/patrol`：`dataSource="live" | "template"` 标注实况/模板；critical 项自动投递全局告警流
