# 04 · 模型与 AI 推理（model · ai）

> 页面：`/settings` → 「模型管理」（`ModelManagementSection`）·「AI / LLM」（`AISection`）
> 关联页：`/models`（24 提供商/69 模型矩阵）· `/ai`（AI 决策）· `/ai-family-models`（成员模型分配）

## 模型管理开关（ModelManagementSection）

| 变量 | 类型 | 默认 | 说明 |
| ---- | ---- | ---- | ---- |
| （消费 `useModelProvider` 面板内开关） | — | — | 模型 CRUD/Ollama 探测在 `/models` 页；本区为入口聚合 |

## AI / LLM 推理参数（AISection）

| 变量 | 类型 | 默认 | 示例 | 说明 / 消费方 |
| ---- | ---- | ---- | ---- | ---- |
| `values.aiApiKey` | string | `""` | `sk-…`（经网关代理填占位） | 调用密钥（生产走 `/console/gw` 服务端注入，浏览器零暴露） |
| `values.aiBaseUrl` | string | `"https://api.openai.com/v1"` | `https://api.0379.world/console/gw/v1` | OpenAI 兼容 base |
| `values.aiModel` | string | `""` | `glm-4-flash` | 默认对话模型 |
| `values.aiTemperature` | string | `"0.7"` | `0.2`（0-2） | 采样温度 |
| `values.aiTopP` | string | `"0.9"` | `0.95` | 核采样 |
| `values.aiMaxTokens` | string | `"2048"` | `4096` | 单次生成上限 |
| `values.aiTimeout` | string | `"30000"` | `60000`（ms） | 请求超时 |
| `toggles.aiStreamMode` | boolean | `true` | 开/关 | 流式输出 |
| `toggles.aiContextMemory` | boolean | `true` | 开/关 | 上下文记忆（AI Assistant 消费） |
