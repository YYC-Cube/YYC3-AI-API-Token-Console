# 07 · 通知与告警（notification）

> 页面：`/settings` → 「通知配置」（`NotificationSection`）；关联页 `/alerts`（告警规则）· `/follow-up`（一键跟进）
> 告警流：WS `alert` 消息 + 本地投递 `pushLocalAlert`（巡查 critical 判定）同队列，上限 100 条最新在前

## 通知渠道

| 变量 | 类型 | 默认 | 示例 | 说明 / 生效 |
| ---- | ---- | ---- | ---- | ---- |
| `toggles.alertEmail` | boolean | `true` | 开/关 | 邮件通知开关 |
| `values.alertEmailAddr` | string | `"admin@cloudpivot.ai"` | `ops@yyc3.vip` | 告警邮箱。**保存时 P4 下发** |
| `toggles.alertSlack` | boolean | `false` | 开/关 | Slack 通知开关 |
| `values.webhookUrl` | string | `""` | `https://hooks.example/x` | 告警 Webhook。**保存时 P4 下发** |

## 告警阈值

| 变量 | 类型 | 默认 | 示例 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| `values.alertGpuThreshold` | string | `"90"` | `85`（%） | GPU 利用率告警阈值 |
| `values.alertTempThreshold` | string | `"80"` | `75`（°C） | 温度告警阈值 |

## 真实告警源（实况）

- **巡查判定**：`/patrol` 实况检查（在线率 <80% 等 critical）→ 自动投递全局告警流（顶栏/告警页同源可见）
- **WS 推送**：后端 `alert` 消息（真实 WS Server 接入后即通）
- 告警数据结构：`{ id, level: info|warning|error|critical, message, source, timestamp }`
