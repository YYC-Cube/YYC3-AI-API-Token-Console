# 05 · 存储与缓存（storage）

> 页面：`/settings` → 「存储配置」（`StorageSection`）；关联页 `/database`（数据库管理）· `/files`（文件管理）

## 备份

| 变量 | 类型 | 默认 | 示例 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| `toggles.autoBackup` | boolean | `true` | 开/关 | 自动备份开关 |
| `values.backupSchedule` | string | `"0 2 * * *"` | `0 4 * * 1`（cron） | 备份计划（每日 02:00 示例） |

## 数据库连接（/database 页同源参数）

| 变量 | 类型 | 默认 | 示例 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| `values.dbHost` | string | `"localhost"` | `192.168.3.45` | 主机 |
| `values.dbPort` | string | `"5433"` | `5432` | 端口 |
| `values.dbName` | string | `"cpim_matrix"` | 自定义库 | 库名 |
| `values.dbUser` | string | `"yyc_admin"` | — | 用户 |
| `values.dbPassword` | string | `""` | — | 密码（仅本地会话，不入远程库文档） |
| `values.dbPoolSize` | string | `"20"` | `10` | 连接池大小（env `DB_POOL_MAX` 默认 10 为兜底） |

## 缓存与压缩

| 变量 | 类型 | 默认 | 示例 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| `toggles.cacheEnabled` | boolean | `true` | 开/关 | 缓存开关 |
| `values.cacheSize` | string | `"512"` | `1024`（MB） | 缓存容量 |
| `values.cacheTTL` | string | `"3600"` | `7200`（秒） | 缓存存活时间 |
| `toggles.dataCompression` | boolean | `true` | 开/关 | 数据传输压缩 |

> env 层同族兜底：`DB_POOL_MIN/MAX/IDLE_TIMEOUT/ACQUIRE_TIMEOUT`（见 [08](./08-环境变量与API端点.md)）。
