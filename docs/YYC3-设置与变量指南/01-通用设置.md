# 01 · 通用设置（general）

> 页面：`/settings` → 左栏「通用设置」（`GeneralSection`，sections-core.tsx）
> 生效：全部即时（settingsBus 全树 + 跨标签页同步）

## 显示与界面

| 变量 | 类型 | 默认 | 取值示例 | 说明 / 消费方 |
| ---- | ---- | ---- | ---- | ---- |
| `toggles.darkMode` | boolean | `true` | 开 / 关 | 深色主题。写 `documentElement[data-theme]` + `meta theme-color`；骨架语义类（yyc3-*）与 CSS 变量层即时切换 |
| `values.refreshInterval` | string | `"5"` | `2/5/10/30/60`（秒） | 数据刷新间隔。驱动 WS 降级模拟与 REST 轮询周期（1-300s 合法，非法兜底 2s） |
| `values.language` | string | `"zh-CN"` | `zh-CN / en / ja` | 界面语言（i18n 语言包） |
| `values.timezone` | string | `"Asia/Shanghai"` | `Asia/Tokyo`、`UTC` | 系统时区展示 |

## 系统信息

| 变量 | 类型 | 默认 | 示例 | 说明 |
| ---- | ---- | ---- | ---- | ---- |
| `values.systemName` | string | `"YYC³ CloudPivot Intelli-Matrix v3.2"` | 自定义名 | 系统名称（顶栏/终端欢迎语，随 settingsBus 即时刷新） |
| `values.clusterId` | string | `"CN-EAST-PROD-01"` | `CN-EAST-DEV-02` | 集群标识（展示 + env `CLUSTER_ID` 同义） |

## 配置导入 / 导出

- **导出配置**：生成含版本元信息 JSON（`version:1` + toggles + values），可入库存档
- **导入配置**：粘贴合法 JSON → 白名单合并生效（非法 JSON 拒绝且状态不变）
- **重置默认**：恢复 19 开关 + 41 值全默认并广播
- **保存更改**：数据在编辑时已持久化（localStorage），按钮触发 P4 服务端下发（见 06）
